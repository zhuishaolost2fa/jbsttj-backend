## 删除剧本 = 软删列表 + 物理清导入副作用（完成）

**需求**：`DELETE /api/v1/scripts/{script_id}` 不只删列表条目，还要清理导入剧本（DM 手册）的全部副作用。

**根因**：副作用表（script_dm_* + script_requests）带 script_id 外键 ON DELETE CASCADE，但删除走软删除（deleted_at + status=offline），级联永不触发，需手动清理。

**实现（4 个文件改动 + 新增测试）**：
- `app/services/dm_store.py`：新增 `purge_script_side_effects(script_id)`——先把非终态任务 PATCH 为 `cancelled`，再按叶子到根删 7 张表：highlights → stories → chunks → qa → questions → documents → jobs
- `app/services/repository.py`：`soft_delete` 新增可选 `extra=`（删除时摘掉 dmGuide）；新增 `count_dm_guide_refs(object_key, exclude_script_id=)` 跨剧本引用计数
- `app/services/script_service.py`：重写 `delete_script` 四步——① `run_in_threadpool(purge_script_side_effects)`（DMStore 是 httpx 同步客户端，FastAPI 事件循环必须线程池包装）② `_delete_guide_object`：files 软删（带 user_id 过滤）→ files 表引用 + 其它剧本 dmGuide 引用双 0 才物理删 OSS 对象（秒传共享引用计数先例）③ 软删剧本行并摘 `extra.dmGuide`/`dm_guide` ④ bump `qa_titles_cache_scope(dm_code)` 缓存版本（同名分片共用聚合 code）
- `app/api/v1/scripts.py`：端点改为接收 `user: CurrentUser` 并传 `user_id`
- `tests/test_script_delete_cleanup.py`：4 用例（Fake 仓储/OSS/DMStore，无需真实 DB），含共享对象不删、无 dmGuide 跳过清理

**关键坑**：`slugify("雾都疑影")` 产出 `wu-dou-yi-ying`（雾都→wu-dou）非 wu-du，测试断言拼错会挂。全量 `pytest tests/` **74 passed**（原 70 + 新 4），四文件 py_compile 通过。
