## import-status：向量化块到上限即判解析完成

需求：embedded_chunks 达到 total_chunks（向量化块到上限）时，parse 相位应直接 done，overallStatus 进入完成态，不必等 finalize 把 job 置 completed。

改动（app/services/dm_service.py `get_import_status`）：
- parse 相位 active 分支新增前置判断：`job.total_chunks > 0 and job.embedded_chunks >= job.total_chunks` → `parse_status="done", progress=100`。用 `>=` 兼容重试导致 += 计数器虚高（embedded > total）。
- 依据：embed_and_store 每批在 chunk 和 QA 都入库后才累加 embedded_chunks，故块到上限时全部内容实际已写完，只差 finalize 落终态的一瞬；继续报 active 会让前端看到"100% 却迟迟不完"。
- 整体状态：parse done 后走既有分支 `overall = "ready" if indexed else "parsed"`。当前因 chunk_and_dedup 会提前写 document.total_chunks（昨日诊断的早写问题，用户未选择修），indexed 此时已为真 → overall 直接 "ready"。

测试：tests/test_import_status.py 新增 4 用例（到上限→ready、超限→done、到上限但 indexed=False→parsed、未到上限→仍 parsing），合计 11/11 通过；test_ingest_stage_detail.py 3/3 通过。

遗留（昨日已诊断、用户暂未要求修）：chunk_and_dedup 提前写 document.total_chunks，导致 QA 生成阶段 ready=done 与 parse=active 短暂并存；且 search 的 indexed 门禁会提前放行（解析中途可问答但索引残缺）。修法备查：chunk_and_dedup 的 update_document 去掉 total_chunks 字段。

## 修复 embeddedChunks 计数器落后真值（+= 丢失）

现象：stageDetail 显示"已向量化 34/34 块 / 53 问答"（真值，来自 count_chunks），但 embeddedChunks 停在 28。34-28=6 恰为一批的量——某批 bump_job 上报失败被静默吞掉（dm_store.py:342 except DatabaseError 只 warning），+= 自增量永久丢失，导致"到上限判完成"（embedded>=total）不触发。
修复（app/tasks/dm_ingest.py embed_and_store）：embedded_chunks/embedded_qa 不再用 bump_job += 自增，改为 `update_job` **绝对值回写**库内实际行数（count_chunks/count_qa，与 finalize 同源）。自愈：某批上报失败下一批自动补回；重试不虚高。多批并行安全（计数单调递增、后写覆盖，最后完成的批次行数最全）。
注意：generate_qa 的 total_qa 仍走 bump_job +=（只用于 stage 文案与 _coarse_progress 兜底，未改）。
测试更新：test_ingest_stage_detail.py 两个 embed 用例改断言 update_job 绝对值回写（12/24、7/9），3/3 + 11/11 全过。

## 修复 dm-guide/ask 纯空白 question 放行

排查用户 curl：`POST /api/v1/scripts/{id}/dm-guide/ask` 请求体里 question 为多个空格。原 `AskRequest.question` 只校验 `min_length=1`，纯空白会通过请求体验证；服务层 `search()` 再 strip 成空并抛 `query_required`。为避免空白输入进入 RAG/LLM 链路，改为在 `app/schemas/dm_guide.py` 的 `AskRequest` 增加 `field_validator("question")`：strip 后为空直接校验失败，非空则保存 trim 后问题。
测试：新增 `tests/test_dm_guide_ask_request.py` 覆盖纯空白拒绝与首尾空白裁剪；用项目 `.venv` 运行新增测试 2/2 通过，现有 `tests/test_import_status.py` 11/11 通过。
