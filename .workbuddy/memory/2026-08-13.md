# 2026-08-13

## ask 接口改为向量直出（速度最优）
- DM 指南问答 `ask` 接口新增 `useLlm` 开关（AskRequest.use_llm，camelCase 别名 useLlm，默认 False）。
- 默认路径不再调用 LLM：直接把向量检索最近命中（qa 答案 / 原文块）透出为 `answer`，仅 1 次 embedding + 向量查询，几十毫秒级、零 LLM 额度。
- `use_llm=True` 才走原 RAG 链路（LLM 合成带引用出处答案）。
- 新增 `_compose_direct_answer(sources)`：取 sources[0]（ask 内已 qa 优先排序）的文本，空列表兜底「手册中未找到相关内容」。
- 改动文件：app/schemas/dm_guide.py、app/services/dm_service.py、app/api/v1/dm_guides.py（两个 ask 端点透传 use_llm）、frontend/dm-ask-demo.html、docs/dm-guide-ask-frontend.md。
- 验证：py_compile 通过；test_dm_guide_ask_request.py 6/6 通过；单元验证 use_llm 解析与 _compose_direct_answer 行为正确。
